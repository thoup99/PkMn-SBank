# Sample Pokémon sprites

The twelve default PNGs and shiny Pikachu PNG are from
[PokeAPI/sprites](https://github.com/PokeAPI/sprites), downloaded on 2026-10-28
from `sprites/pokemon/<dex>.png` and `sprites/pokemon/shiny/25.png`.
The existing upstream pokeldn sprite cache uses the same source.

These files are bundled only for offline demonstration. Pokémon and related
